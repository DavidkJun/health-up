# 🏋️‍♂️ Health-Up

**Health-Up** is a web fitness application that helps users track their workouts and progress on the way to better health.  
The goal is to make training more organized, convenient, and motivating.

---

## ✨ Core Features
- 📅 Store workout history
- 📝 Add exercises, sets, reps, and weight
- 🔍 View past workouts
- ✏️ Edit and delete workouts

---

## 🛠️ Tech Stack
- **Backend:** NestJS (Node.js)
- **Database:** PostgreSQL 
- **API:** REST
